## 2026-10-20 — Issue #6 공식 OPS 원문 연결 구현 / 실제 API 수집 미검증

- EPO 공식 OPS 안내·공정 이용 안내·OPS 3.2 OpenAPI 및 참조 매뉴얼을 확인.
  자동 수집에는 공식 REST를 안내하며 OPS는 개발자 등록·OAuth 인증이 필요함.
  문헌 이미지 조회의 `FullDocument`와 전체 페이지 수를 읽고 공식 단일 페이지 PDF를 순서대로 수신하는 방식을 구현.
- `--original-method auto|browser|ops` 추가. `auto`는 환경 키가 있으면 OPS를 원문에 우선 사용하며
  없으면 기존 브라우저. API 수집은 동일 공보·종별·전체 페이지 수를 Espacenet 뷰어와 대조하고
  페이지 PDF를 조립한다. 웹에서 받은 단일 원본 파일과 바이트 동일하다고 주장하지 않음.
- 사용자에게 OPS 계정·키가 없음을 확인. 자격증명 없는 JP3102826U 이미지 조회 1회는 HTTP 403.
  인증된 실제 OPS 다운로드 및 실문헌 페이지 수/시각 검수는 키 발급 후 남아 있음. 이슈를 닫지 않음.
- 정상 Chrome 동일 세션의 JP2006198019A, JP2004121879A 브라우저 원문 요청: 15초 대기에서는
  첫 문헌 9페이지 수신·뷰어 대조 성공, 둘째 수신 시간 초과. 새 세션에서 기본 40초로 한 차례 재검증 시 두 문헌 모두 수신 시간 초과.
  매칭한 다운로드 HTML의 보안문자 응답 검출은 모두 0이었으나, 이는 모든 UI에서 보안문자가 없었다는 증거가 아님.
  시간 초과 원인과 보안문자 발생 조건을 확정하지 않았으며 기존 브라우저 완전 무인화 성공으로 보고하지 않음.
- `download_metrics`로 다운로드 방식·검출 횟수·수신/반복/시간 초과·대기 시간을 결과 JSON에 기록.
  실제 매칭 보안문자 응답을 검출하면 안내하고 동일 창의 파일 수신을 기다림. 답안·요청 헤더·토큰은 기록하지 않음.
- `run_with_ops.py`는 로컬 터미널에서 Key/Secret을 숨김 입력받고 해당 프로세스에서만 사용하며 종료 시 이전 환경을 복원.
  계정 등록·무료 유형 선택·활성화·앱 키 발급 안내 추가. 계정 가입이나 약관 동의를 대행하지 않음.
- 전체 자동 테스트 63개 실행: 62개 통과, 개인 샘플 검사 1개 생략.
  OPS 응답·페이지 PDF는 모의 응답으로 검증. 정확한 종별·전체 수신 순서·페이지 불일치 중단·HTML 거절·키 없는 사전 중단·키 환경 복원·브라우저 전체 다운로드 대체·검출 통계를 포함.

## 2026-10-20 — 동일 JP3102826U AI 번역 병합 재검수

- 사용자 추가 요청에 따라 영문 초록 누락 시 Codex가 같은 공보 원문 초록을 번역하고, 원문 초록도 없을 때만
  명세서에서 AI 요약하는 보완 절차를 추가. Python이 AI를 호출하는 것은 아니며 Codex가 원문을 읽고 검토 JSON을 작성함.
- 이번 JP3102826U는 원문 1페이지에 일본어 초록이 있어 AI 요약이 아닌 **원문 초록의 AI 번역**으로 처리.
  원문 표지의 과제·해결수단·선택도면을 전사하고 영어 번역을 문장별 대조함. 명칭도 원문에서 번역했으며
  권리자·고안자 영문 표기는 기존 J-PlatPat 기계번역 표기를 참고했다는 점을 앞장에 표시.
- 앞장에 `AI TRANSLATION - NOT AN OFFICIAL ENGLISH ABSTRACT`를 표시. 영어 서지·초록과 원문 대표도면으로
  A4 1페이지를 만들고 공식 원문 8페이지를 이어 붙여 총 9페이지 생성. 앞장 전체 시각 검수 완료.
  도면은 원문 위치에서 잘라낸 것으로 그림 자체를 다시 그리거나 생성하지 않음.
- 공식 원문은 이전 실사이트 수집본의 SHA-256을 재확인해 재사용. 새 다운로드로 보고하지 않음.
  병합 후 8페이지 전체 디코딩 콘텐츠 스트림이 원본과 동일함을 확인했고 헤더만 있는 8페이지도 보존.
- OS 다운로드 폴더에 `JP 3102826 U.pdf`와 결과 XLSX/JSON/ZIP 저장. 결과 상태 `AI 번역 보완`,
  `result_type=ai_assisted_reference`, `translation_type=ai_translation`, `complete_reference=false`.
  `ai_provenance`에 근거 원문·페이지·영문 번역·검토 근거를 기록. `ai_assisted=1`, 실패 0으로 별도 집계.
- 자동 테스트 54개 실행, 실패 0 / 개인 샘플 환경 미설정 검사 1개 생략.
  번역/요약 구분, 공보·종별·원문 해시·페이지 수 검증, 원문 전 페이지 보존, 중복 행 및 AI 결과 ZIP 포함을 검증.
  원문 초록 없는 AI 요약 경로는 로컬 모의 문서로 검증했으며 실제 공보의 AI 요약 사례를 수집한 것은 아님.

## 2026-10-20 — Issue #5 JP3102826U 자료 누락 처리

  J-PlatPat 서지의 총 7페이지 표기와 Espacenet 스캔 8페이지는 구분함.
- [J-PlatPat 동일 공보](https://www.j-platpat.inpit.go.jp/c1801/PU/JP-3102826/25/en)의 영문 화면은 기계번역임을 확인.

  정상 인계·비정상 종료·준비 시간 초과를 모의 검사했으며 과거 오류의 원인을 확정한 것은 아님.

## 2026-10-15 당시 실사이트 제한

독립 Playwright 세션에서 Espacenet은 HTTP 403을 반환했다. 내장 브라우저에서는 JP 샘플의
서지·영문 초록·Original document 9페이지·전체 다운로드 링크를 확인했다.
KIPRIS는 KPA 수집·인쇄에 성공했지만 국내 전문 상세 요청이 사이트 오류 주소
`fail.kipris.or.kr/error.html`로 이동하여 브라우저가 혼합 콘텐츠를 차단했다.
보안 설정을 완화하지 않았으며, 해당 세션에서 **온라인 수집부터 최종 병합까지 완주한 것으로 표시하지 않는다.**
위 내용은 최초 테스트 기록이다. 2026-10-16 Espacenet 사용자 확인 방식의 성공은 상단 추가 조사 기록을 따른다.
전문 뷰어/blob 다운로드 코드는 실제 UI 구조를 기반으로 작성했으나 정상 세션에서의 추가 실증이 필요하다.
`--profile`/`--cdp` 또는 공식 사이트에서 검토하여 받은 로컬 자료 + manifest 경로를 사용한다.

JP 샘플은 영문 서지 1 + 원문 9 = 10페이지다.
KR 제공 샘플은 영문 KPA 1 + 파일 첨부 안내지 1 + 공보 원문 19 = 21페이지다.
안내지를 빼고 요청한 두 자료만 병합하면 KR은 20페이지가 된다.
샘플 자체에는 PDF 객체 오프셋 경고가 있으며, 이는 새 수집본의 정상 여부를 판단하는 근거로 삼지 않는다.

