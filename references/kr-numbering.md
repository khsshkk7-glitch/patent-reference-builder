# 한국 특허·실용신안의 번호와 역할

번호의 **권리 유형**, **출원/공보 역할**, **공보 종별**을 서로 대체하지 않는다.
11자리라는 길이만으로 특허 접두부 10을 붙이지 않는다. U도 출원 식별자와 공개공보에서 서로 다른 문맥으로 쓰일 수 있다.

## 공식 근거와 확인 표본

- [WIPO 공개·등록번호 조사, KR 표](https://www.wipo.int/edocs/mdocs/cws/en/cws_8/cws_8_9-annex1.html): 실용신안 연도형 공보의 20 접두부와 등록 일련번호 형식을 설명한다.
- [KIPO K-PION 번호 체계](https://www.kipo.go.kr/en/HtmlApp?c=50200&catmenu=ek02_05_03): 출원/공개/공고 번호는 권리 유형 2자리+연도 4자리+일련번호 7자리이며 등록번호와 구분한다.
- [KIPO Authority File 설명](https://www.kipo.go.kr/en/HtmlApp?c=60105&catmenu=ek07_01_04): A/U 공개공보와 B1/Y1 공고 자료의 종별을 구분한다.

2026-10-22 공식 KIPRIS 원문과 사용자가 제공한 Espacenet 서지 화면을 대조한 표본:

| 문맥 | 확인 표기 | 구분 |
|---|---|---|
| KIPRIS 공개실용신안공보 U, 공개일 2007-01-05 | 공개번호 20-2007-0000036 | 출원번호가 아님 |
| 위 동일 원문의 (21) 출원번호 | 20-2006-0031687 | 공개번호와 연도·일련번호가 다름 |
| Espacenet KR200355113Y1의 Application number 필드 | KR20040008221U | 이 표본에서는 출원 식별자이며 U 공개공보 존재를 입증하지 않음 |
| 동일 KIPRIS 등록실용신안공보 Y1의 (21) 출원번호 | 20-2004-0008221 | 위 출원 식별자와 대응 |
| 위 Y1 공보의 (11) 등록번호 | 20-0355113 | 출원번호를 그대로 공개/등록번호로 사용하지 않음 |

Espacenet 화면은 사용자 제공 당시의 공식 화면이며 이번 웹 조회 도구로 해당 Espacenet 페이지를 새로 열지는 못했다.
KIPRIS U 원문은 이번에 6페이지를 직접 재수집해 첫장과 끝장을 확인했다. 국내 13자리 U 표기와 11자리 U 표기로
조회한 원문 바이트가 모두 같았다. 해당 시험은 원문 수집 및 정규화 시험으로, 번역/완성 참증 검수 완료 시험은 아니다.

## 구현 규칙

- 명시한 10/20 국내 접두부를 기억하며, 종별과 모순되면 입력을 거부한다.
- 확인된 A/B 종별은 특허 10, U/Y 종별은 실용신안 20과 구분한다. KR 11자리에서 유형을 알 수 없으면
  파일명에 10이나 20을 임의로 추가하지 않으며 KIPRIS 국내 번호 변환도 오류로 중단한다.
  국내 접두부가 명시된 번호 또는 공식 화면에서 확인한 정확한 종별로 다시 입력한다.
- 공보 역할의 `KR20070000036U`와 `KR 20-2007-0000036 U`는 `KR20070000036U`로 정규화한다.
  KIPRIS 검색은 `2020070000036`, 공보 원문 표지 대조는 `20-2007-0000036`, 파일명은 `KR 20-2007-0000036 U.pdf`다.
- 종류 없는 `KR 20-2007-0000036`도 권리 유형 20을 보존한다. 같은 연도/일련번호의 A 공보를 후보로 주더라도
  그쪽으로 조용히 전환하지 않는다. 종류 없는 11자리만 주면 A/U 등 복수 종별의 모호성을 그대로 유지한다.
- 출원 역할의 `KR20040008221U`는 `ap=KR20040008221U`, 국내 번호는 `2020040008221`이다.
  `--role application` 또는 출원번호 헤더가 필요하며 공보로 자동 승격하지 않는다.
  검토된 매핑에서 publication=KR200355113Y1과 application=정규화된 요청 출원번호를 대조해야 한다.
- U가 없는 국내 출원번호 `KR 20-2004-0008221`은 기존처럼 13자리 `KR2020040008221`을 유지한다.
  모든 출원 식별자나 모든 11자리 번호를 20형으로 일괄 교체하지 않는다.
- 공보의 국내 20 연도형 입력은 정규화 키가 달라질 수 있다. 이전 버전에서 만든 13자리 U/종류 없는 연도형
  공보 manifest는 새 `--dry-run`의 key에 맞춰 새로 검토한다. 해시·공보번호·역할을 확인하지 않고 키나 검수 플래그만 바꾸지 않는다.

결과 입력 계획에는 `kr_right`가 10/20/빈값으로 남는다. 파일명과 KIPRIS 검색·표지 대조는 같은 판단을 사용한다.
중복 재사용도 번호·역할·권리 유형을 함께 구분한다. 같은 숫자의 종류 미지정 10/20 입력이 서로의 PDF를 재사용하지 않는다.
